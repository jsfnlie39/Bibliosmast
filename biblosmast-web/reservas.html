Reservas

Una reserva aparta un libro para un usuario hasta la fecha de vencimiento. Cuando haya un ejemplar disponible, se atiende registrando el préstamo: la reserva del usuario para ese libro pasa sola a Atendida.

Nueva reserva

«Vencida» se calcula sola cuando pasa la fecha de vencimiento. Una reserva atendida o cancelada ya no se edita.
